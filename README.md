# Demo Renamer

Плагин для сервера Project Reality (BF2). Переименовывает автоматические
демки `auto_*.bf2demo` в понятные имена:

```
demo_<дата_время>_<карта>_<режим>_<слой>.bf2demo
demo_2026_09_01_19_45_00_assault_on_grozny_gpm_cq_128.bf2demo
```

Все данные берутся из самой демки: время начала записи, карта, режим и слой.

## Требования

- На сервере включена автозапись демок (`sv.autoRecord 1` в `serversettings.con`).
- Демки пишутся в `mods/pr/demos/`.
- Есть модуль `game.realitytimer` (входит в PR).

## Установка

1. Скопируйте `demo_renamer.py` в `mods/pr/python/game/`.
2. Подключите его там, где загружаются остальные Python-модули сервера,
   например в `mods/pr/python/game/__init__.py`:

   ```python
   import demo_renamer
   demo_renamer.init()
   ```

3. Перезапустите сервер.

При успешном запуске в логе сервера появится строка
`DemoRenamer: initialized`.

## Как работает

1. Когда раунд переходит в статус Playing, запускается таймер на 245 секунд
   (демка появляется примерно через 4 минуты после начала раунда).
2. Плагин берёт самую новую `auto_*.bf2demo` в папке демок.
3. Читает из неё время, карту, режим и слой и переименовывает файл.
4. Если не получилось (демки ещё нет, файл занят), повторяет каждые 10 секунд,
   до 12 попыток.

Время в имени — это начало записи демки, оно примерно на 4 минуты позже
начала раунда.

## Настройки

В начале `demo_renamer.py`:

| Параметр     | По умолчанию      | Что задаёт                               |
|--------------|-------------------|------------------------------------------|
| `DEMO_DIR`   | `mods/pr/demos/`  | папка с демками                          |
| `PLAY_DELAY` | `245.0`           | задержка после Playing, секунды          |
| `RETRY_WAIT` | `10.0`            | пауза между повторными попытками, секунды|
| `RETRIES`    | `12`              | число попыток                            |

## Лог

Все сообщения идут в консоль сервера с префиксом `DemoRenamer:`.

| Сообщение            | Значение                                              |
|----------------------|-------------------------------------------------------|
| `initialized`        | плагин загружен                                       |
| `renamed to <имя>`   | демка переименована                                   |
| `failed: <ошибка>`   | все попытки исчерпаны, демка осталась `auto_*`        |
| `init failed: ...`   | плагин не запустился (нет `realitytimer` и т.п.)      |
| `error: ...`         | непредвиденная ошибка; сервер продолжает работать      |

Ошибки плагина никогда не роняют сервер — они только пишутся в лог.
