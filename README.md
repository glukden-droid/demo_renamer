# Demo Renamer

Плагин для сервера Project Reality (BF2). Переименовывает автоматические
демки `auto_*.bf2demo` в понятные имена:

```
demo_<дата_время>_<карта>_<режим>_<слой>.bf2demo
demo_2026_09_01_19_45_00_assault_on_grozny_gpm_cq_128.bf2demo
```

Все данные берутся из самой демки: время начала записи, карта, режим и слой.

## Требования

- На сервере включена автозапись демок (`sv.autoRecord 1` в `serversettings.con`).
- Демки пишутся в `mods/pr/demos/`.

## Установка

1. Скопируйте `demo_renamer.py` в `mods/pr/python/game/`.
2. Подключите его там, где загружаются остальные Python-модули сервера,
   например в `mods/pr/python/game/__init__.py`:

   ```python
   import demo_renamer
   demo_renamer.init()
   ```

3. Перезапустите сервер.

При успешном запуске в логе сервера появится строка
`DemoRenamer: initialized`.

## Как работает

1. Когда начинается раунд (Playing), плагин просматривает папку демок.
   Демка прошлого раунда к этому моменту закрыта и выгружена сервером,
   а новая появится только примерно через 4 минуты.
2. Для каждой `auto_*.bf2demo` читает из файла время, карту, режим и слой
   и переименовывает её.
3. Если файл прочитать не удалось, он остаётся `auto_*`, в логе появляется
   `skip ...`, и в начале следующего раунда плагин попробует снова.

Демка получает новое имя в начале следующего раунда. Время в имени — это
начало записи демки, оно примерно на 4 минуты позже начала раунда.

Папка демок задаётся параметром `DEMO_DIR` в начале `demo_renamer.py`
(по умолчанию `mods/pr/demos/`).

## Лог

Все сообщения идут в консоль сервера с префиксом `DemoRenamer:`.

| Сообщение            | Значение                                              |
|----------------------|-------------------------------------------------------|
| `initialized`        | плагин загружен                                       |
| `renamed to <имя>`   | демка переименована                                   |
| `skip <файл>: ...`   | файл не прочитан, остался `auto_*`                    |
| `init failed: ...`   | плагин не запустился                                  |
| `error: ...`         | непредвиденная ошибка; сервер продолжает работать      |

Ошибки плагина никогда не роняют сервер — они только пишутся в лог.
