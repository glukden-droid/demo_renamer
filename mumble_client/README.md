# Клиент Mumble 1.5 для сервера Project Reality

Отдельный проект, не связан с `demo_renamer`. Собирает клиент Mumble последней
версии ветки 1.5 (по умолчанию `v1.5.939`) из официальных исходников
<https://github.com/mumble-voip/mumble>. Клиент совместим с сервером 1.5.

Сборка включает плагины позиционного звука (`-Dplugins=ON`).

## Windows (для игроков)

1. GitHub → **Actions** → **Mumble client** → **Run workflow**.
2. При необходимости укажите другой тег (например, `v1.5.940`).
3. Когда сборка закончится, скачайте артефакт `mumble-client-<тег>-win64`:
   в нём установщик `.msi`.

Workflow лежит в `.github/workflows/mumble-client.yml` и использует официальные
скрипты сборки Mumble под Windows (vcpkg, статическая сборка).

## Linux

```bash
./build_linux.sh            # v1.5.939
./build_linux.sh v1.5.940   # другой тег
```

Результат: `build/mumble-<тег>/mumble`. Скрипт ставит зависимости через `apt`
(Debian/Ubuntu).
